## ✨ 功能概述

多模型横向排列功能让你可以同时对比多个AI模型的回答，就像一个AI竞技场！

### 核心特性

1. **简化操作** - 2步即可开启多模型对话
2. **横向排列** - 直观对比多个模型回复
3. **并发请求** - 所有模型同时回复
4. **独立操作** - 每个模型可单独操作
5. **Token统计** - 横向显示所有模型统计
6. **响应式设计** - 移动端自动适配

## 🚀 技术亮点

### 1. 消息分组算法
使用 `useMemo` 智能分组消息，将连续的多模型assistant消息归为一组

### 2. 卡片式设计
每个模型有独立的卡片界面，包含：
- 头部：头像、名称、提供商
- 内容：Markdown渲染
- 操作：复制、重试按钮
- 底部：性能指标、时间戳

### 3. 响应式布局
- 桌面端：横向排列，最多4个卡片
- 移动端：自动调整宽度，支持滚动

### 4. 性能优化
- 消息分组缓存
- 条件渲染
- 批量更新

## 🔍 常见问题

### Q: 为什么最多只能选择4个模型？
A: 为了保证界面清晰和性能流畅。4个模型可以在不横向滚动的情况下看到所有回复。

### Q: 多模型模式会消耗更多Token吗？
A: 是的，每个模型都会独立计费。建议在需要对比时使用。

### Q: 可以在移动端使用吗？
A: 可以！移动端会自动调整卡片宽度，支持横向滚动。

### Q: 如何单独重试某个模型？
A: 点击该模型卡片底部的"重试"按钮即可。
