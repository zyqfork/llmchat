## 开发者视角

### 消息结构

```typescript
interface ChatMessage {
  role: "user" | "assistant";
  content: string;
  isMcpResponse?: boolean;  // 标记为 MCP 响应
  mcpCalls?: Array<{        // MCP 调用信息
    toolName: string;
    clientId: string;
    rawJson: string;
  }>;
}
```

### 消息处理流程

```
原始消息
  ↓
filterMcpMessages()
  ↓
- 过滤掉 isMcpResponse: true 的消息
- 提取 MCP 调用信息到 mcpCalls
- 移除 JSON 代码块
  ↓
渲染消息
  ↓
- 显示清理后的内容
- 显示可展开的工具调用组件
```

### 关键代码位置

1. **消息过滤**：`app/components/chat.tsx` - `filterMcpMessages()`
2. **工具调用展示**：`app/components/chat.tsx` - MCP tool calls section
3. **样式**：`app/components/chat.module.scss` - `.mcp-tool-calls`
4. **调试模态框**：`app/components/chat.tsx` - `debugModalOpen` section

## 常见问题

### Q: 为什么看不到 MCP 调用的 JSON？
A: 默认是折叠的，点击 `🔧 调用工具: xxx` 可以展开查看。

### Q: 如何复制调试信息？
A: 直接在调试模态框中选中文本，然后 Ctrl+C 复制。

### Q: 工具调用失败了怎么办？
A: 查看 AI 的错误提示，或点击调试按钮查看详细的请求/响应信息。

### Q: 可以同时调用多个工具吗？
A: 可以，每个工具调用都会显示为独立的可展开项。

### Q: MCP 响应消息去哪了？
A: 被过滤掉了，因为用户不需要看到原始的 JSON 响应。AI 会处理这些响应并生成友好的答案。

## 设计原则

1. **简洁优先**：默认隐藏技术细节
2. **按需展开**：需要时可以查看详情
3. **保持连贯**：消息流程自然流畅
4. **易于调试**：开发者可以轻松查看和复制调试信息
