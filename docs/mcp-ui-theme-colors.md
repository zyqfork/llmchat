# MCP 工具调用 - 主题配色说明

## 设计理念

MCP 工具调用组件使用应用的主题 primary 颜色（蓝色），确保与整体 UI 风格保持一致。

## 颜色变量

### 浅色模式
```scss
--primary: #3b82f6;        // 主蓝色
--primary-light: #60a5fa;  // 浅蓝色
--primary-dark: #2563eb;   // 深蓝色
```

### 深色模式
```scss
--primary: #60a5fa;        // 主蓝色（更亮）
--primary-light: #93c5fd;  // 浅蓝色
--primary-dark: #3b82f6;   // 深蓝色
```

## 视觉效果

### 折叠状态（默认）

```
┌─────────────────────────────────┐
│ 🔧 调用工具: search          ▼ │  ← 蓝色边框
│                                 │     蓝色文字
│                                 │     半透明蓝色背景
└─────────────────────────────────┘
```

**样式**：
- 边框：1px solid `var(--primary)` (#3b82f6)
- 背景：`rgba(59, 130, 246, 0.05)` - 5% 透明度
- 文字：`var(--primary)` (#3b82f6)
- 工具名称：蓝色背景 + 白色文字

### 悬停状态

```
┌─────────────────────────────────┐
│ 🔧 调用工具: search          ▼ │  ← 背景变深
└─────────────────────────────────┘
```

**样式**：
- 背景：`rgba(59, 130, 246, 0.1)` - 10% 透明度（更深）

### 展开状态

```
┌─────────────────────────────────┐
│ 🔧 调用工具: search          ▲ │  ← 深蓝色边框
├─────────────────────────────────┤     带阴影
│ {                               │
│   "method": "tools/call",       │
│   "params": {                   │
│     "name": "search",           │
│     ...                         │
│   }                             │
│ }                               │
└─────────────────────────────────┘
```

**样式**：
- 边框：`var(--primary-dark)` (#2563eb) - 更深的蓝色
- 阴影：`0 2px 8px rgba(59, 130, 246, 0.15)` - 蓝色阴影
- 标题背景：`rgba(59, 130, 246, 0.08)` - 8% 透明度

## 深色模式适配

### 自动适配

使用 CSS 变量 `var(--primary)` 会自动根据主题切换颜色：

**浅色模式**：
- `var(--primary)` → #3b82f6 (标准蓝)

**深色模式**：
- `var(--primary)` → #60a5fa (亮蓝)

### 深色模式特殊处理

```scss
.dark {
  .mcp-tool-call {
    background-color: rgba(96, 165, 250, 0.08);  // 使用深色模式的蓝色
    
    &[open] {
      box-shadow: 0 2px 8px rgba(96, 165, 250, 0.2);
    }
  }
}
```

## 动画效果

### 过渡动画

```scss
transition: all 0.2s ease;
```

**应用于**：
- 边框颜色变化
- 背景颜色变化
- 阴影出现/消失
- 悬停效果

### 交互反馈

1. **悬停**：背景变深（0.05 → 0.1 透明度）
2. **展开**：边框变深 + 添加阴影
3. **折叠**：移除阴影 + 边框恢复

## 可访问性

### 颜色对比度

- **浅色模式**：蓝色 (#3b82f6) 在白色背景上 - WCAG AA 级别 ✅
- **深色模式**：亮蓝色 (#60a5fa) 在深色背景上 - WCAG AA 级别 ✅

### 视觉提示

- 🔧 图标：清晰的工具调用标识
- ▼/▲ 箭头：明确的展开/折叠状态
- 悬停效果：明显的交互反馈
- 阴影效果：展开状态的深度感

## 与其他组件的一致性

### 主题色使用

MCP 工具调用组件使用与以下组件相同的 primary 颜色：

- 主按钮
- 链接
- 选中状态
- 进度条
- 其他强调元素

### 设计语言

- 圆角：8px（与卡片、按钮一致）
- 内边距：8px 12px（与其他小组件一致）
- 字体大小：13px（与辅助文字一致）
- 字体粗细：500（medium weight）

## 实现细节

### SCSS 代码

```scss
.mcp-tool-call {
  // 使用主题变量
  border: 1px solid var(--primary);
  
  // 半透明背景（浅色模式）
  background-color: rgba(59, 130, 246, 0.05);
  
  // 平滑过渡
  transition: all 0.2s ease;
  
  summary {
    color: var(--primary);
    font-weight: 500;
    
    code {
      background-color: var(--primary);
      color: var(--white);
    }
  }
  
  &[open] {
    border-color: var(--primary-dark);
    box-shadow: 0 2px 8px rgba(59, 130, 246, 0.15);
  }
}

// 深色模式覆盖
.dark .mcp-tool-call {
  background-color: rgba(96, 165, 250, 0.08);
}
```
