# MCP Function Call 快速开始

## 5 分钟快速配置

### 步骤 1: 打开 MCP Market

在应用中点击侧边栏的 MCP Market 图标，或访问 `/mcp-market` 路由。

### 步骤 2: 添加 MCP 服务器

1. 点击 "添加服务器" 按钮
2. 选择一个内置服务器（如 `smithery-websearch`）
3. 点击 "添加" 按钮
4. 等待服务器状态变为 "Running"（绿色）

### 步骤 3: 选择调用模式

滚动到页面底部，找到 "MCP 配置区域"：

#### 选项 A: 提示词模式（推荐新手）
- ✅ 兼容所有模型
- ✅ 可自定义提示词
- ⚠️ 依赖模型理解能力

#### 选项 B: 函数调用模式（推荐高级用户）
- ✅ 更精确的工具调用
- ✅ 节省 token
- ⚠️ 需要模型支持 Function Call

### 步骤 4: 保存配置

点击 "保存配置" 按钮。

### 步骤 5: 开始对话

1. 返回聊天界面
2. 在会话设置中启用 MCP
3. 询问需要使用工具的问题，例如：
   - "搜索最新的 AI 新闻"
   - "帮我查找 Python 教程"

## 验证配置

### 检查服务器状态

在 MCP Market 页面：
- ✅ 绿色 "Running" = 正常
- ⚠️ 黄色 "Initializing" = 初始化中
- ❌ 红色 "Error" = 错误

### 检查工具调用

在对话中：
1. 观察模型是否调用工具
2. 查看工具调用结果
3. 确认最终回复是否使用了工具结果

## 常见问题

### Q: 模型不调用工具？

**Prompt 模式：**
- 检查系统提示词是否正确注入
- 尝试更明确地要求使用工具
- 考虑自定义提示词

**Function Call 模式：**
- 确认模型支持 Function Call
- 检查工具定义是否正确传递
- 查看浏览器控制台的错误信息

### Q: 工具调用失败？

1. 检查 MCP 服务器状态
2. 查看错误信息
3. 尝试重启服务器
4. 检查网络连接

### Q: 如何切换模式？

1. 打开 MCP Market
2. 滚动到底部
3. 选择新的调用模式
4. 点击 "保存配置"
5. 刷新页面（可选）

### Q: 哪些模型支持 Function Call？

支持的模型：
- ✅ OpenAI GPT-4 系列
- ✅ OpenAI GPT-3.5-turbo
- ✅ OpenAI GPT-4o 系列
- ✅ Azure OpenAI（对应模型）
- ✅ 部分兼容 OpenAI API 的第三方模型

不确定的模型：
- 先尝试 Prompt 模式
- 如果模型支持，再切换到 Function Call 模式

## 进阶配置

### 自定义提示词（Prompt 模式）

1. 在 MCP 配置区域点击 "编辑"
2. 修改工具模板或系统模板
3. 点击 "保存"

### 管理多个服务器

1. 添加多个 MCP 服务器
2. 每个服务器可以独立启动/停止
3. 工具会自动合并到一起

### 调试工具调用

1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签页
3. 查看 Network 标签页的请求详情
4. 检查请求中的 `tools` 参数

## 最佳实践

### 1. 选择合适的模式

- **新手**：使用 Prompt 模式，兼容性好
- **高级用户**：使用 Function Call 模式，更精确
- **生产环境**：根据模型选择，优先 Function Call

### 2. 优化提示词

在 Prompt 模式下：
- 明确说明工具的用途
- 提供清晰的调用示例
- 强调格式要求

### 3. 监控工具调用

- 定期检查服务器状态
- 观察工具调用成功率
- 根据需要调整配置

### 4. 处理错误

- 为工具调用失败准备备用方案
- 提供清晰的错误提示
- 记录错误日志以便调试
